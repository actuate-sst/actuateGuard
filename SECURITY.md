# Security policy

This repo controls access to a real gate. If you find a way to open it, keep it open, stop it opening, or fake or erase log entries, please report it privately.

**How to report:** use GitHub's **"Report a vulnerability"** button under this repo's *Security* tab, or message @shreyansh-malviya directly. Please don't open a public issue or PR for it.

**Leaked a secret by accident?** (key, token, WiFi password) Tell @shreyansh-malviya straight away. Deleting the commit isn't enough; the secret has to be rotated.

The design is meant to stay secure **even though the code is public**. Read [docs/design.md](docs/design.md) §10 for the known residual risks before reporting those.

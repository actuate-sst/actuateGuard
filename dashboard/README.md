# dashboard/

Admin web dashboard. Design: [docs/design.md §3](../docs/design.md#3-components).

**Not started yet.**

Features:
- Admin login with **passkey or TOTP 2FA**
- Create invites, approve pending members
- Issue guest grants (short expiry)
- Revoke a person or device
- Access log: filter by person and date, and show each gate's last sync time

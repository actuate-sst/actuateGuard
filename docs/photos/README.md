# docs/photos/

Photos and screenshots used in the README and docs.

## Wanted

| File | What | Issue |
|---|---|---|
| `board-bench.jpg` | Gate controller on the bench (ESP32 + relay + RTC), top-down, good light | "Photo: gate board on the bench" |
| `relay-closeup.jpg` | Relay module showing its labelling (active-low/high jumper, if any) | "Photo: relay module close-up" |
| `bench-wiring.jpg` | Real photo of the relay wired to an exit button on the bench, to go with the diagram in `hardware/wiring.png` | "Photo: bench wiring" |
| `app-*.png` | App screenshots: onboarding, unlock, denied | "Screenshots: phone app" (after the app exists) |
| `dashboard-*.png` | Dashboard screenshots: members, guests, logs | "Screenshots: dashboard" (after it exists) |

## Rules (this repo is public)

- ✅ Bench photos, close-ups of modules, drawn diagrams, screenshots with **mock data only**
- ❌ The installed gate, its location, the outside of the gate, the enclosure in place, the lock make/model, or wiring as mounted
- ❌ Anything showing real names, phone numbers, invite codes, QR codes, keys or WiFi details
- Strip location data (EXIF/GPS) before committing. Most phones add it.
- Keep each image under ~500 KB (resize to ~1600 px wide).
